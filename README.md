## 📖 About The Voidmaw
**The Voidmaw** is an ancient abyssal entity dwelling in the interdimensional rifts of digital space[cite: 1]. Composed of over 20,000 sentient energetic tetrahedrons, it continuously reshapes its writhing black tendrils around a burning core eye[cite: 1]. The entity feeds on dimensional chaos, reacting in real-time as you tweak parameters such as core size, tendril reach, and crimson gaze intensity[cite: 1].

---

## 🎛️ Swarm Parameters & Customization
The application features adjustable parameters to control the behavior and geometry of the entity:
* **Core Size:** Range 10 - 40 (Default: 22)[cite: 1]
* **Tendril Count:** Range 4 - 16 (Default: 9)[cite: 1]
* **Tendril Reach:** Range 20 - 100 (Default: 55)[cite: 1]
* **Writhing Speed:** Range 0 - 5 (Default: 2.2)[cite: 1]
* **Eye Gaze Glow:** Range 0 - 5 (Default: 3.0)[cite: 1]
* **Corruption Chaos:** Range 0 - 5 (Default: 2.5)[cite: 1]
* **Particle Count:** 20,000[cite: 1]
* **Auto Rotation:** Toggleable feature[cite: 1]
